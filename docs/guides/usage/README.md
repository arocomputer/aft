# Usage

Run `aft` for a compact command overview. `aft help` and `aft --help` show
all commands. Use `aft help on` or `aft on --help` to see a command's flags.

- [Sessions](sessions.md)
- [Launchers](launchers.md)
- [Ports](ports.md)
- [Configuration](config.md)
- [Mounted projects](mounts.md)
- [Uninstall](uninstall.md)

Aft's own output is plain text. Session, host and mount listings use compact
lines without column headers. `aft doctor` reports problems and completed
repairs, or `ok` when healthy; `aft doctor --json` includes every finding.
